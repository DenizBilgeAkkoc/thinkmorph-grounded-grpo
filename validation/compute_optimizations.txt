The production A100 training run and its source were not changed. RTX allocation 1965089 remains reserved.

WHAT CHANGED:
1. Generate the eight text rollouts together; retain production replay pairs of two.
   Every recorded action is validated and replayed exactly once; each rollout retains its RNG stream.
2. Run FP32 VAE encoder/decoder convolutions on GPU, with TF32 disabled.
   Keep posterior sampling and scale/shift on CPU, preserving CPU RNG consumption exactly.
   Component encode/decode speedup: 28–33x. Decoded 8-bit images differed by at most one intensity level in the fixed-input test.
3. Reduce replay layer recomputation when memory permits. Auto mode retains checkpointing above 2048 query tokens.

REAL GRPO BACKWARD, using each archived trajectory's own real judge rewards:
  Question 0: 40.14s -> 35.12s; question 1: 26.95s -> 23.37s.
  12.8% less backward time, identical gradients across all 784 LoRA gradient tensors; two repetitions per setting.
  Memory rose from 32.8–33.8 GiB to 38.0–44.0 GiB. These tests stop before an optimizer step.

IMAGE FLOW BATCHING: stage-only batch4 reduced flow integration by 10–26% on two shapes.
Fresh batched generation/replay agreed; replaying old singleton likelihoods at larger width did not.
This optimization is not included in the full sampling candidate; it requires matching generation/replay artifacts.

LIVE TRAINING LIMIT:
The full two-rank / two-update / four-question comparison did not complete because concurrent Gemini uploads timed out.
HTTP/2 passed isolated probes, but concurrent large uploads also timed out. Both transports and failed artifacts are retained.
No transport failure was scored as zero. No synthetic rewards, substitute judgments, or claimed successful optimizer updates.
Thus there is no measured end-to-end training speedup, reward-quality conclusion, or full new-candidate distributed checkpoint proof.
A short live-judge training validation remains necessary before adopting these changes on A100.
